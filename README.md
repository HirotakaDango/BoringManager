# BoringManager

<img width="1366" height="685" alt="image" src="https://github.com/user-attachments/assets/c4e17acd-c10b-49ab-8441-123a56cccd51" />

A lightweight, single-file PHP file manager packed into **1 line of code**.

## ✨ Features

- **File Operations:** Create files/folders, rename, delete, and view file info/permissions.
- **Chunked Upload:** Upload large files reliably in chunks.
- **In-Browser Editor:** Edit text/code files directly with instant save notifications.
- **Media Previews:** Built-in viewer for images, audio, video, PDFs, and code.
- **Archive Support:** Create and extract `.zip` files.
- **Search & Navigation:** Recursive search across subdirectories with breadcrumb navigation.
- **Security:** Optional master password authentication.

## 🚀 Quick Start

1. Copy the code into a file named `index.php` (or any `.php` file).
2. *(Optional)* Set a password by editing `$AUTH_PASSWORD='your_password';` near the beginning of the file.
3. Upload to your PHP server and open it in your browser.
